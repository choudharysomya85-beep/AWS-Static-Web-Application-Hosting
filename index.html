AWS CLOUD COMPUTING

Static Web Application

About the Project

This project demonstrates how a static website can be hosted using Amazon Web Services (AWS).

AWS Services Used

Amazon EC2

Used to host and run the web application.

Amazon S3

Used for storing website files and backups.

IAM

Used to manage AWS permissions and access.

Project Objective

The objective of this project is to understand cloud computing concepts and deploy a static web application using AWS services.
