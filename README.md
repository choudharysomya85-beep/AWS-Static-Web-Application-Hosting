# AWS Cloud Computing - Static Web Application

## About the Project

This project demonstrates a static web application using AWS cloud
computing services.

## AWS Services Used

- Amazon EC2 - Used to host and run the web application.
- Amazon S3 - Used to store website files and backups.
- IAM - Used to manage permissions and access.

## Project Objective

The objective of this project is to understand cloud computing and
deploy a static web application using AWS services.

## Technologies Used

- HTML
- CSS
- Amazon EC2
- Amazon S3
- AWS IAM
